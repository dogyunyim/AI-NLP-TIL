### 서브워드 실습에서 다룬 것

- 공개 NSMC 리뷰에서 `document` 열을 추출하고 결측 문장을 제외
- SentencePiece **Unigram**과 Hugging Face Tokenizers **BPE + Whitespace**로 사전 크기 5,000 설정
- 분절된 토큰의 빈도와 문장·코퍼스 인코딩 시간 확인
- 새로운 표현의 분절 결과와 사용 경험 정리

수업 과제 안내와 작성 코드가 함께 포함된 학습 노트북입니다. 실행 출력은 당시 기록이며, 라이브러리 전체의 성능 우열이나 실무 서비스의 개선 수치를 의미하지 않습니다.

## 읽거나 실행하는 방법

1. GitHub에서 노트북의 코드와 저장된 출력을 먼저 확인합니다.
2. 재실행하려면 노트북 첫 셀의 **Open in Colab**을 사용합니다.
3. 설치·데이터 다운로드부터 순서대로 실행합니다. 데이터는 외부 공개 주소에서 내려받으며 인터넷 연결이 필요합니다.
4. 원본은 Colab의 `/content` 경로를 가정합니다. 설치 버전은 고정되지 않았으므로 현재 환경에서 동일한 실행·시간 결과를 보장하지 않습니다.

이번 정리는 **문서·코드의 정적 검토**입니다. 모델 재학습, 최신 환경 재실행 또는 속도 재측정은 하지 않았습니다. 원본 노트북과 과거 실행 결과는 수정하지 않았습니다.
